# Triage labels

| Canonical role  | Tracker label   | Meaning                          |
| --------------- | --------------- | -------------------------------- |
| needs-triage    | needs-triage    | Awaiting evaluation              |
| needs-info      | needs-info      | Waiting for reporter information |
| ready-for-agent | ready-for-agent | Fully specified for an agent     |
| ready-for-human | ready-for-human | Requires human implementation    |
| wontfix         | wontfix         | Will not be actioned             |

Use these mappings whenever a skill names a canonical triage role.
